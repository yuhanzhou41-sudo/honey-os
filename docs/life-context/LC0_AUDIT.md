## 真机验证

1. 用测试账户或公开页面，分别选取一个 B 站视频和一个浏览器页面，再测试小红书和 PDF 阅读器。先查看手机 ActivityWatch 版本并抽查两个应用的使用区间。
2. 用经源码审查的本地探针，从默认空白名单开始，先只授权两个测试应用。单独检查页面标题、作者、URL 和可见文字，测量重复进入、滚动、切后台和锁屏，删除设备上产生的探针样本。
3. 用合成批次验证本地传输，断开互联网和电脑后重连，确认重复送达只导入一次。分别检查手机队列、Windows 接收目录和上游存储的残留。
4. 将可核实的字段、失败原因、延迟和耗电填入采集矩阵。提交脱敏样本前删除账号、令牌、私聊和原始 URL 查询参数。B 站和浏览器都至少取得一条真实内容级证据后才通过 LC-0。
