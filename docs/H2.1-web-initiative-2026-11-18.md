# HoneyOS H2.1 网页主动联系

正式 Gateway 运行版本为 `a4f21a8ff1f434f8cd8d342132f4d46de6e4c031`，发布目录为 `/home/zyh20/projects/honeyos-releases/h2-web-a4f21a8f`。设置页的主动联系已开启，通知在 HoneyOS 聊天中持久化，复用现有消息事件的网页刷新路径。

- 本机时区 08:00–23:00 最多每小时判断一次，23:00–08:00 最多每三小时一次。已关闭每日条数限制和整段静默期。
- 活跃回复及最近 15 分钟内有网页用户消息时跳过检查。Qwen 与聊天状态评估复用本地生成的单请求锁。主动联系评估读取情绪轴、模拟状态、已采纳人格和近期自己的意愿。
- Qwen 允许沉默。只有返回明确的联系意愿与理由，才调用主模型。主模型也可以返回 `NO_MESSAGE`。模型生成后再次核对开关、活跃会话和用户活动。发送仅走本机网页适配器。
- 正式 Gateway 缺少旧版话题调度器所依赖的环境标记。最终版本直接为活动网页适配器启动独立任务，首个检查于北京时间 11:54:25 取得评估窗口。

验收通过 55 项前端测试、91 项后端测试、2 项子测试及生产构建。隔离测试验证白天、深夜、活跃聊天、负判断和生成期间关闭开关的行为。正式环境的 Gateway 与 Qwen 健康检查、设置资源和主动联系开关通过检查。
