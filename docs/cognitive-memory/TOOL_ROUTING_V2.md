# 工具路由 V2

Gateway 根据当前消息和当前平台已配置工具选择本轮工具。规则先行；
明确提醒、记忆回顾和单领域请求由规则处理。歧义文本最多调用本地
Qwen 一次，等待上限 3 秒。分类器忙、不可用、响应无效或置信度不足时
沿用现有安全工具集。空消息和附件等结构化内容不送分类器。

分类请求包含固定分类说明和最多 1500 字的当前消息，无聊天历史、
资料正文、记忆条目或工具定义。工具选择与平台配置取交集，权限和
工具执行审批保持原状。

聊天实际模型仍由会话锁定、请求与全局设置决定。分类结果只作用于
HoneyOS 自己的工具循环，不切换模型。Codex CLI 代管整轮时，其自带工具和
通过 MCP 暴露的 HoneyOS 工具不受这份每轮工具清单约束。
已定时提醒的触发和发送无需经过路由器。
