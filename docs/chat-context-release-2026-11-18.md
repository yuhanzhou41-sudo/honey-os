### 评估后新增的项目

- **附件索引与按需重开**。已有重看按钮，下一步是让用户在同一会话里明确提到旧文件时，能从候选中定位它。多份同名或指代不清时先让用户确认。随后可用本地附件引用减少网页历史接口的 Base64 传输。安排在 H3 首条闭环之后。
- **聊天上下文与用量验收**。记录每轮历史文字、记忆、Study 摘录和图片占用，尽可能使用提供方实际返回的用量，缺失时标明估算。用同一组合成长聊和大附件比对压缩前后请求与回答。可随 H3 验收补齐，现阶段没有实测 token 节省比例。
- **工作恢复**。保存任务进度、候选版本和未决澄清。重启后可选择恢复，已经执行或过期的一次性审批保持失效。纳入 H3.4，优先于开放更多执行器。
