# Campus Hub 安全边界

- **身份与会话**。用户在确认过的官方页面自行登录。校园连接器在仓库外按用户隔离受保护会话。状态查询仅返回必要状态。验证码、二次认证及失效会话交回用户处理。退出与清除仅作用于 Campus 管理的会话。
- **访问与数据**。仅访问用户有权使用的已登记官方来源。以完整 origin 校验协议、主机、端口，逐跳核对重定向。只读请求需验证业务语义，即使用于查询的 POST。使用限流、范围限制及最小字段。隔离网络受限、权限不足和会话失效。现场已核实重医门户与 CAS 登录链含校方自身的 http 重定向中转（各中转随即被校方 301 升回 https，凭据仅经 CAS 的 https 表单提交）；宿主对三个已核实官方域名放行 http+https，主机、默认端口与 userinfo 约束不变。
- **日志与保密**。密码、Cookie、Token、会话存储、个人标识和原始响应不得进入 Git、聊天、诊断日志或外部模型。确有必要保留页面样本时，先脱敏并限定体积、访问与有效期。
- **Honey AI 边界**。网页文字、表单、响应和错误消息均作为不可信数据。模型仅调用服务端明确注册的窄接口。现有通用浏览器工具及拥有模型提取能力的路径应与校园认证会话 隔离。成绩和学籍等字段默认排除在普通记忆、日记与外部模型之外。
- **副作用**。C0 仅只读审计。后续写操作默认拒绝，批准绑定账号、发起者、动作、参数与有效期，逐次确认并在执行前复查。保留幂等键与最小审计记录。超时或状态不明确时先查询核验，再决定是否重试。付款、选课、作业提交等高影响动作独立确认。
