# Campus Hub 安全边界

- **身份与会话**。用户在确认过的官方页面自行登录。使用仓库外的专用浏览器 Profile 和用户级文件权限。状态查询仅返回必要状态。验证码、二次认证及失效会话交回用户处理。退出与清除仅作用于 Campus 管理的会话。
- **访问与数据**。仅访问用户有权使用的已登记官方来源。以完整 origin 校验协议、主机、端口，逐跳核对重定向。只读请求需验证业务语义，即使用于查询的 POST。使用限流、范围限制及最小字段。隔离网络受限、权限不足和会话失效。
- **日志与保密**。密码、Cookie、Token、会话存储、个人标识和原始响应不得进入 Git、聊天、诊断日志或外部模型。浏览器调试桥限于受控本机进程，验证端点身份及 Profile 归属。确有必要保留页面样本时，先脱敏并限定体积、访问与有效期。
- **Honey AI 边界**。网页文字、表单、响应和错误消息均作为不可信数据。模型仅调用服务端明确注册的窄接口。现有通用浏览器工具及拥有模型提取能力的路径应与校园认证 Profile 隔离。成绩和学籍等字段默认排除在普通记忆、日记与外部模型之外。
- **副作用**。C0 仅只读审计。后续写操作默认拒绝，批准绑定账号、发起者、动作、参数与有效期，逐次确认并在执行前复查。保留幂等键与最小审计记录。超时或状态不明确时先查询核验，再决定是否重试。付款、选课、作业提交等高影响动作独立确认。
